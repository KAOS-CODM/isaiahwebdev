My Development Journey

My journey started in Computer Science, where a simple curiosity about how browsers render web pages grew into a full-blown passion for development. I taught myself HTML, CSS, and JavaScript, then pushed into Node.js and Express for backend logic, MongoDB for data persistence, and Tailwind CSS for rapid, utility-first styling. Every project — from a recipe-sharing platform to a full fintech dashboard — sharpened my skills in building responsive, accessible, and scalable web applications.

I believe great software is built at the intersection of technical excellence and human-centered design. That's why I focus on clean, maintainable code, performance optimization, and accessibility standards that make the web work for everyone. I stay current with modern workflows like Git and GitHub for version control, and I'm always exploring new tools to deliver better user experiences. Whether I'm optimizing a layout for mobile or architecting a full-stack solution, my end goal is the same — build something that truly works.
