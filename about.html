My Development Journey

My journey started with curiosity — I wanted to know how a website actually gets made. That question turned into learning HTML, CSS, and JavaScript, then into Node.js and Express for backend logic, MongoDB for data, and React and Tailwind CSS for building more complex interfaces. Working through my own projects taught me how the frontend, API, and database have to fit together.

I learn by building. Every project starts with the problem rather than the technology, and I choose the tools that fit it. I keep components small and readable, test as I go, and track my changes with Git. Three ideas guide the work: build with purpose, learn by building, and keep improving.

Alongside my degree I'm completing freeCodeCamp's frontend HTML and CSS course, which I'm applying directly to the interfaces in my projects. The certificate is in progress — not yet earned.
